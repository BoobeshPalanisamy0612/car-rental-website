## 📖 Overview

**RentWheels** is a high-performance, single-page application built using **React 19** and **Vite**. Designed with a modern UI/UX approach, it provides users with an intuitive interface to browse car fleets, inspect vehicle specifications, and explore transparent pricing plans.

Whether viewing on a desktop, tablet, or smartphone, RentWheels adapts fluently across all viewports while maintaining high FPS transitions and minimal bundle size.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **🏎️ Fleet Showcase** | Interactive vehicle collection with full spec breakdowns (fuel, transmission, capacity). |
| **📱 Mobile-First Layout** | Fluid layout engine optimized for all viewport sizes and touch devices. |
| **⚡ Blazing Fast Performance** | Instant HMR and quick module loading powered by Vite. |
| **🎯 Dynamic Booking UI** | Streamlined multi-step inquiry forms built for minimal user friction. |
| **💰 Transparent Pricing** | Highlighted membership/rental tiers with clear feature callouts. |
| **📞 Contact Hub** | Quick-action customer support section with responsive micro-interactions. |
